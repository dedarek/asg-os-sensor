# Goose 学习产物 → 通用文件计划（PoC 原语）

顾问新增 `runtime/learned_install.py`。本模块不是目标产品 adapter，不包含目标目录或 Hook 模板；目录及文件内容由后续真实 Goose 产物提供。当前只完成本地安装原语，未声称自主生成、目标加载或完整接入已验证。

## 输入
`version: 1`，`files` 为非空数组，每项含：
- `path`：授权工作区内相对路径；不得为绝对路径、穿越路径或软链接。
- `content`：需要写入的完整文本。
- `expected_sha256`：新建文件为 null；修改既有文件必须为调查时原内容的摘要，变化则拒绝覆盖。

## 调用边界
调查阶段只能提交候选，不直接调用安装。监督程序验证真实证据、角色、作用域及生成代码的隔离试验后，传入精确 `approved_workspace`、`approved_digest`。安装器不运行命令、不重启目标，返回 installed/already_installed 和 activation=unverified。

状态和原内容备份存入监督者控制的独立目录；幂等复用检查当前文件摘要；撤销只恢复未被用户改动的文件。MVP针对独立可控工作区，未处理恶意并发文件系统竞争或断电恢复，不宣称生产安全沙箱。
